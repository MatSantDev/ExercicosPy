# ExercicosPy

Resolução dos exercícios da [Lista de Exercícios da comunidade Python Brasil](https://wiki.python.org.br/ListaDeExercicios), feitos para praticar a lógica de programação em Python.

## Conteúdo

| Pasta | Exercícios |
|-------|-----------|
| `Estrutura sequencial` | 18 — entrada e saída, operações matemáticas e conversões |
| `Estrutura de decisão` | 28 — `if`/`elif`/`else` e validações |
| `Estrutura de repetição` | 3 — laços `while`/`for` e validação de dados |

Cada arquivo `exNNN.py` traz o enunciado no topo, como comentário, seguido da solução.

## Como executar

```bash
python "Estrutura sequencial/ex001.py"
```

## Tecnologias

Python 3
